# Web & API Testing

> web and API application testing

## Who it's for

For application and API security testers.

## What this role does

Proxies, fuzzers, content discovery, injection and CMS tooling, and TLS checks for web and API assessments.

## Installing

Pick this role in **Hemo Welcome** on first boot, or add it later:

```sh
sudo hemo-roles
```

Tools install online at selection time. See the [main README](../../README.md#roles) for the role model.
