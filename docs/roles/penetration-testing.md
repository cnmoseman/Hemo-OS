# Penetration Testing

> generalist assessment across recon, AD, web, passwords, and exploitation

## Who it's for

For generalist penetration testers running broad assessments.

## What this role does

A full assessment kit spanning reconnaissance, Active Directory, web and API, password attacks, and exploitation. Cloud and OSINT tooling folds in here too.

## Installing

Pick this role in **Hemo Welcome** on first boot, or add it later:

```sh
sudo hemo-roles
```

Tools install online at selection time. See the [main README](../../README.md#roles) for the role model.
