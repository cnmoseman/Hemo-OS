# Full Scope

> every role's tools combined, for purple-team work and labs

## Who it's for

For anyone who wants the complete kit, including purple-team work.

## What this role does

Installs the union of every role's tools in one box.

## Tools

Full Scope installs every other role's tools combined. See the individual role pages:

[Red Team](red-team.md) · [Penetration Testing](penetration-testing.md) · [Web & API Testing](web.md) · [Reverse Engineering](reverse-engineering.md) · [Blue Team Host Analyst](blue-host-analyst.md) · [Blue Team Network Analyst](blue-net-analyst.md) · [Vulnerability Assessment](vulnerability-assessor.md)

## Installing

Pick this role in **Hemo Welcome** on first boot, or add it later:

```sh
sudo hemo-roles
```

Tools install online at selection time. See the [main README](../../README.md#roles) for the role model.
